WHAT IT DOES

사람이 하기 귀찮은 것만 골라서

상위 노출에 실제로 영향을 주는 항목만 자동으로 처리합니다.

🔍

뚫을 수 있는 키워드 찾기

네이버 검색광고 API 로 월 검색량과 경쟁도를 봅니다. 검색량만 큰 키워드는 경쟁이 심하니 쓰지 말라고 알려줍니다.

📸

사진 정리

크기를 줄이고, 순서대로 이름을 바꾸고, GPS 같은 개인정보를 지웁니다. 같은 사진이 두 번 들어갔으면 잡아냅니다.

✍️

본문 작성

업체명·가격·시술 내용을 넣으면 그대로 반영해 씁니다. 모르는 값은 절대 지어내지 않고 채울 자리로 남깁니다.

✅

발행 전 검사

글자수, 키워드 밀도, 소제목 수, 과장 표현, 협찬 표기 누락을 확인합니다. 밀도 2% 를 넘기면 경고합니다.

CAUTION

자동 발행을 넣지 않은 이유

“매크로로 올리면 편한데 왜 안 하냐”는 질문에 대한 답입니다.

네이버가 이미 막아둔 길입니다

  • 네이버는 2020년 5월 블로그 글쓰기 API를 폐지했습니다. 폐지 사유가 “광고성 글 대량 제작·게재”였습니다. 공식 자동 발행 경로는 존재하지 않습니다.
  • 남은 방법은 매크로뿐인데, 이용약관 위반 + 로그인 차단 + 어뷰징 패턴 노출이 한꺼번에 걸립니다.
  • 2~3분 간격 대량 발행은 지금 네이버가 제재를 강화하겠다고 밝힌 바로 그 패턴입니다.
  • 저품질에 걸리면 글은 남아 있는데 검색에서만 빠집니다. 회복까지 몇 달, 또는 영구입니다.

하루 한 편만 올리세요. 몰아서 올리는 것이 가장 확실한 자멸 방법입니다. 사진은 직접 찍은 것만 쓰고, 협찬을 받았으면 본문에 명시하세요(표시광고법 의무).

내 컴퓨터에서만 도는 서버입니다. 사진과 API 키는 컴퓨터를 벗어나지 않습니다.

글 생성을 위해 Claude API 로 보내는 텍스트만 예외입니다.
