# 모모필라테스 홈페이지

“필라테스를, 처방합니다” — 모모필라테스 브랜드 선언문의 슬로건과 대표 컬러를
그대로 가져와 만든 원페이지 홈페이지입니다. 빌드 도구나 프레임워크 없이
HTML·CSS·JS 파일 세 개로 동작합니다.

## 브랜드 기준

| 항목 | 값 |
| --- | --- |
| 슬로건 | We **prescribe** Pilates. / 필라테스를, **처방**합니다 |
| 구조 | Diagnosis(진단) → Prescription(처방) |
| 대표 컬러 | `#cc785c` |
| 배경 / 잉크 | `#faf8f5` / `#2b2926` |
| 위치 | 광주 상무 |

브랜드의 “처방” 개념을 페이지 구조로 썼습니다. 프로그램은 **처방전 형식**
(진단 / 처방 / 용법)으로 조판되어, 회차와 기간이 그대로 용법·용량으로 읽힙니다.
수업 강도는 기구에 거는 **스프링 개수**로 표시합니다.

히어로의 척추 그림은 구부정한 자세에서 중립 정렬로 펴지는 과정을 두 곡선 사이
보간으로 그린 것입니다. 목·허리의 통증 표시가 자세가 펴질수록 함께 옅어집니다.

## 실행

정적 파일이라 서버가 필요 없지만, 웹폰트는 `file://`에서 CORS로 막히므로
로컬 서버로 여는 것을 권합니다.

```sh
python3 -m http.server 8000
# http://localhost:8000
```

## 채워 넣어야 할 자리

아래 값은 모두 자리표시자입니다. 실제 정보로 바꿔 주세요.

**`index.html`**

- 전화번호 — `000-0000-0000` (본문 표시용)과 `tel:0000000000` (링크용) 각 3곳
- 주소 — `광주광역시 서구 ○○로 00, 0층` (오시는 길, 푸터)
- 교통 안내 — `상무역 0번 출구에서 도보 0분`
- 운영 시간 — 오시는 길 섹션의 `월–금 / 토 / 일·공휴일`
- 원장 이름 `○○○`, 보유 자격·경력 4줄 (원장 소개, 푸터 대표자)
- 원장 사진 — `.teacher__portrait` 자리에 `<img>`를 넣으세요 (4:5 비율)
- 수업료 표 — 실제 금액과 회차
- 사업자등록번호

**`assets/js/main.js`** 맨 위 `CONFIG`

```js
var CONFIG = {
  kakaoUrl: "",      // 카카오톡 채널 주소
  formEndpoint: "",  // 예약 폼을 받을 주소 (구글폼·Formspree 등)
  phone: "000-0000-0000"
};
```

`formEndpoint`를 비워 두면 폼 제출 시 전화로 안내하는 문구가 뜹니다. 주소를
넣으면 그대로 전송됩니다. `kakaoUrl`도 같은 방식으로 동작합니다.

## 폰트

CDN을 쓰지 않고 직접 담았습니다. 서브셋한 파일이라 전부 합쳐 약 515KB입니다.

| 용도 | 폰트 | 크기 |
| --- | --- | --- |
| 한글·본문 | Pretendard Variable (KS X 1001 2350자 서브셋) | 432KB |
| 영문 표제 | Cormorant Garamond Variable (정체 + 이탤릭) | 36KB |
| 숫자·라벨 | Archivo Variable | 46KB |

브랜드 선언문은 Noto Sans KR을 썼지만, 여기서는 자모 균형과 굵기 범위가 더 넓은
Pretendard로 바꿨습니다. Noto Sans KR을 그대로 쓰시려면 `styles.css`의
`--font-kr` 값만 바꾸면 됩니다.

Pretendard 서브셋은 KS X 1001 한글 2350자를 담고 있어 일반적인 한국어 문장은
모두 표시됩니다. 서브셋에 없는 희귀 음절을 쓰면 시스템 폰트로 대체됩니다.

## 파일 하나로 합치기

CSS·JS·폰트를 전부 심어 넣은 단일 파일을 만듭니다. 외부 요청이 없어 어디서든
그대로 열립니다.

```sh
python3 tools/build_single_file.py        # dist/index.html (약 737KB)
```

## 배포

`index.html`과 `assets/` 폴더를 그대로 올리면 됩니다. GitHub Pages, Netlify,
Vercel, 일반 웹호스팅 모두 추가 설정 없이 동작합니다.

## 만들어 둔 것

- 밝은 화면과 어두운 화면 모두 대응 (`prefers-color-scheme`)
- 모바일 하단 고정 바 (전화 · 카카오톡 · 예약)
- 애니메이션 최소화 설정(`prefers-reduced-motion`) 존중
- 키보드 포커스 표시, 본문 바로가기 링크, 스크린리더용 도표 설명
- 가로 스크롤 없음 (390px 기준 확인)
