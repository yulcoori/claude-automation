# nblog — 네이버 블로그 글쓰기 도구

브라우저에서 키워드와 사진, 매장 정보를 넣으면 **글이 실시간으로 써집니다.**
터미널은 처음 설치할 때 한 번만 씁니다.

```
블로그글만들기.bat 더블클릭  →  브라우저가 열림  →  입력하고 '글 만들기'
```

| 넣는 것 | 나오는 것 |
|---|---|
| 키워드 (예: 풍암동미용실) | 월 검색량·경쟁도, 제목 후보 5개, 태그 |
| 사진 (끌어다 놓기) | 크기·이름·중복 정리, 본문 배치 자리 |
| 매장 정보 (아는 것만) | 업체명·가격·시술이 반영된 본문 |
| — | 발행 전 품질 검사 (글자수·키워드 밀도·과장 표현) |
| — | 스마트에디터 붙여넣기용 서식 복사 |

## ⚠️ 먼저 읽어주세요 — 자동 발행은 넣지 않았습니다

"네이버에 걸려서 지수 떨어지지 않나?" → **떨어집니다. 그것보다 더 나쁠 수도 있습니다.**

- 네이버는 **2020년 5월 블로그 글쓰기 API를 폐지**했습니다. 폐지 사유가 "광고성 글 대량 게재"였습니다. **공식 자동 발행 경로는 존재하지 않습니다.**
- 남은 방법은 매크로뿐인데, 이건 이용약관 위반 + 로그인 차단 + 어뷰징 패턴 노출이 한꺼번에 걸립니다.
- 2~3분 간격 대량 발행은 지금 네이버가 **제재를 강화하겠다고 밝힌** 바로 그 패턴입니다.
- 저품질에 걸리면 회복까지 몇 달, 또는 영구입니다. 상위노출을 얻으려고 검색 노출 자체를 잃습니다.

그래서 **발행 버튼만 사람이 누르는** 구조로 만들었습니다. 자동화되는 노동의 90%는
어차피 리서치와 초안 작업이고, 그건 전부 이 도구가 합니다.

자세한 근거와 출처: **[docs/naver-risk.md](docs/naver-risk.md)**

## 설치

### Windows — 더블클릭만

1. 이 저장소를 내려받습니다.
2. **`블로그글만들기.bat`** 를 더블클릭합니다.

처음 실행할 때 필요한 준비(가상환경, 패키지 설치)를 자동으로 하고 브라우저가 열립니다.
파이썬이 없으면 설치 안내가 나옵니다 ([python.org](https://www.python.org/downloads/) —
설치 시 **Add Python to PATH** 체크).

### macOS / Linux

```bash
git clone <이 저장소>
cd claude-automation
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pip install -e .
nblog web        # 브라우저가 열립니다
```

## API 키 발급 (전부 무료)

```bash
cp .env.example .env
```

| 키 | 발급처 | 용도 | 없으면 |
|---|---|---|---|
| `NAVER_AD_*` | [searchad.naver.com](https://searchad.naver.com) → 도구 > API 사용 관리 | 키워드 검색량·경쟁도 | 연관 키워드를 상위 글 제목에서만 추출 |
| `NAVER_CLIENT_*` | [developers.naver.com](https://developers.naver.com/apps/#/register) (사용 API = 검색) | 상위 노출 글 역분석 | 제목 길이·최신성 분석 생략 |
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com) | 본문 초안 생성 | 초안 대신 `prompt.md` 생성 (복붙해서 쓰면 됨) |

셋 다 없어도 돌아갑니다. 다만 네이버 키 중 하나는 있어야 리서치가 의미가 있습니다.

## 사용법

### 브라우저 (권장)

```bash
nblog web
```

키워드를 넣고, 사진을 끌어다 놓고, 아는 매장 정보를 채우고 **글 만들기**를 누르면
글이 한 글자씩 써지는 걸 보면서 기다립니다. 끝나면 **네이버 에디터용 복사**를 눌러
스마트에디터에 붙여넣으면 제목·소제목·목록 서식이 그대로 유지됩니다.

내 컴퓨터에서만 도는 서버입니다(127.0.0.1). 사진과 API 키는 컴퓨터를 벗어나지 않고,
글 생성을 위해 Claude API 로 보내는 텍스트만 예외입니다.

### 명령줄 — 원스톱

```bash
python -m nblog build "제주도 렌트카 추천" -i ./사진폴더 \
  --shop "OO렌트카" --price "하루 4만원" --service "아반떼 3일"
```

1. 연관 키워드 40개를 뽑아 검색량·문서수·진입난이도를 계산
2. 상위 노출 30개 글의 제목 길이·숫자 사용률·최신성을 역분석
3. 제목 후보 5개 + 목차 + 태그 + 목표 분량을 설계
4. 사진을 리사이즈·EXIF 정리·순서대로 이름 정리하고 중복을 검사
5. 본문 초안 작성 (경험을 채울 자리는 `{{직접 채우기}}` 로 비워둠)
6. 발행 전 품질 검사 (키워드 밀도, 분량, 과장 표현, 협찬 표기…)

### 개별 명령

```bash
# 어떤 키워드로 쓸지 고르기
python -m nblog keyword "제주도 렌트카"

#  키워드                    월검색량   모바일     문서수  문서/검색  난이도
#  ─────────────────────────────────────────────────────────────────────
#  제주도렌트카                 74,200    88%    1,204,331     16.2  어려움
#  제주공항렌트카가격            2,910    91%       48,102     16.5  어려움
#  제주도렌트카보험자차           480    86%        3,201      6.7  보통
#  ← 검색량은 적어도 '문서/검색'이 낮은 쪽이 신규 블로그가 뚫을 수 있는 키워드

# 상위권이 어떤 형태로 쓰는지 보기
python -m nblog serp "제주도 렌트카"

# 사진만 정리
python -m nblog images ./사진 -k "제주도 렌트카" -o out/images

# 설계안만
python -m nblog plan "제주도 렌트카" --json plan.json

# 다 쓴 글을 발행 전에 검사
python -m nblog audit out/제주도-렌트카-2026-08-06/post.md
```

`audit` 은 `{{직접 채우기}}` 가 남아 있거나 키워드 밀도가 2.5%를 넘으면
종료 코드 2를 반환합니다 (CI 에 걸어도 됩니다).

## 발행 순서

1. `post.md` 를 열어 `{{직접 채우기}}` 를 **실제 경험**으로 채웁니다 ← 가장 중요한 단계
2. `python -m nblog audit post.md --write` 로 재검사
3. `post.html` 을 브라우저로 열고 전체 복사 → 스마트에디터에 붙여넣기
4. 노란 박스 자리에 `images/` 사진을 업로드하고 박스를 삭제
5. `guide.md` 의 태그를 복사해 붙이고 → 발행

## 운영 수칙 (지켜야 효과가 있습니다)

- **하루 1편.** 몰아서 올리는 게 가장 확실한 자멸 방법입니다.
- **사진은 직접 찍은 것만.** 다운로드 이미지는 중복 판정을 받습니다.
- **키워드 밀도 2% 이하.** `audit` 이 잡아줍니다.
- **경험을 반드시 넣으세요.** 네이버 D.I.A. 는 "작성자만 쓸 수 있는 정보"를 봅니다. 자동 생성 문장만으로는 상위권에 못 갑니다.
- **협찬은 본문에 명시.** 표시광고법 의무이고 미표시는 과징금 대상입니다.

## 하지 않는 것

이 저장소에는 다음 코드가 없고, 앞으로도 넣지 않습니다.

- 네이버 로그인 자동화 / 세션 탈취 / 캡차 우회
- 스마트에디터 매크로 조작
- 이미지를 변조해 중복 탐지를 피하려는 처리 (효과도 없습니다 — 네이버는 메타데이터가 아니라 이미지 특징으로 판정합니다)
- 유사 문서 양산

## 프로젝트 구조

```
src/nblog/
├── config.py     .env 로딩, 키 유무 판정
├── naver.py      검색광고 API + 오픈API 클라이언트 (읽기 전용)
├── research.py   상위 글 역분석 → 포스팅 설계안
├── context.py    매장 정보 (업체명·가격·시술 등)
├── images.py     사진 최적화 + 중복 검사
├── draft.py      Claude API 초안 생성 (스트리밍 지원)
├── audit.py      발행 전 품질 검사
├── render.py     산출물 패키지 생성
├── webapp.py     브라우저 화면 서버 (FastAPI + SSE)
├── web/          화면 HTML
├── gui.py        데스크톱 창 (tkinter) — 웹 화면을 권장합니다
├── theme.py      데스크톱 창 스타일
└── cli.py        명령줄
```
