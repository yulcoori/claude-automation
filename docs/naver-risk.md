# 자동 발행을 넣지 않은 이유

> 요약: **네이버에 걸립니다.** 지수가 떨어지는 정도가 아니라, 블로그 전체가
> 검색에서 누락되거나 계정이 정지될 수 있습니다. 그래서 이 도구는 발행 직전까지만 합니다.

---

## 1. 공식 발행 경로가 이미 막혔습니다

네이버는 **2020년 5월 6일 블로그 글쓰기 API를 종료**했습니다. 로그인 없이 외부
프로그램에서 글을 바로 게재할 수 있게 해주던 기능인데, 서비스 10년째에 닫았습니다.

닫은 이유가 정확히 우리가 하려던 그것입니다 — 언론 보도에 따르면 "일부 사용자가
광고 수수료를 얻기 위해 광고성 글을 API로 대량 제작·게재"한 것이 종료 사유였습니다.
기사 제목이 그대로 **"광고성 블로그 퇴출 위해 글쓰기 API 종료"** 입니다.

즉, "네이버랑 연결해서 업로드" 하는 **정상적인 방법은 현재 존재하지 않습니다.**

## 2. 남은 방법은 매크로뿐이고, 그게 위험의 본체입니다

공식 경로가 없으니 자동 업로드를 하려면 Selenium/Puppeteer 같은 걸로 브라우저를
띄워 로그인하고 스마트에디터를 조작해야 합니다. 여기서 세 가지가 동시에 터집니다.

**(1) 이용약관 위반**
자동화 수단으로 서비스에 접근하는 행위는 네이버 이용약관이 금지하는 항목입니다.
적발 시 이용 제한 대상이고, 이건 알고리즘 감점과 별개인 계정 조치입니다.

**(2) 로그인 자체가 막힙니다**
네이버 로그인은 자동화 도구를 탐지합니다. 새 기기·비정상 클라이언트로 인식되면
캡차, 2차 인증, 로그인 차단이 걸립니다. 이걸 우회하려고 만드는 코드는 그 자체로
부정 접근 시도이고, 저는 그런 코드는 작성하지 않습니다.

**(3) 발행 패턴이 그대로 증거로 남습니다**
네이버가 보는 것은 글 내용만이 아닙니다.

| 신호 | 사람이 쓸 때 | 매크로가 쓸 때 |
|---|---|---|
| 글 하나 작성 시간 | 30분 이상 | 2~3분 |
| 발행 간격 | 불규칙, 하루 1편 내외 | 일정, 시간당 20편 |
| 이미지 | 직접 촬영, 매번 다름 | 재사용/다운로드, 해시 중복 |
| 문서 유사도 | 낮음 | 템플릿 기반이라 높음 |

2026년 기준으로 이건 이미 사회적 문제가 된 상태입니다. 한 건강 블로그가 하루에
102개 글을 2~3분 간격으로 올린 사례가 보도되면서, **네이버는 제재 강화 방침을
밝혔습니다.** 지금 이 패턴으로 들어가는 건 강화 중인 필터에 정면으로 걸어들어가는
셈입니다.

## 3. 네이버가 저품질 기준을 공개하지 않는 이유

"어디까지 괜찮은지 선을 알려주면 그 선까지만 하겠다"가 안 되는 이유이기도 합니다.
네이버가 저품질 알고리즘 가이드를 공개하지 않는 명시적 이유는 **공개하면 어뷰징에
악용되기 때문**입니다. 즉 기준은 계속 바뀌고, 오늘 통과한 방식이 다음 달에 소급
적용될 수 있습니다. 매크로 기반 운영은 구조적으로 시한폭탄입니다.

그리고 저품질은 회복이 느립니다. 새 글이 검색에 안 잡히기 시작하면 원인을 특정할
수도 없고, 정상화까지 몇 달이 걸리거나 아예 돌아오지 않습니다. 상위노출을 얻으려고
검색 노출 자체를 잃는 교환입니다.

---

## 그래서 이 도구가 하는 일

발행 버튼을 누르는 것만 사람이 하고, 그 앞의 모든 노동은 자동입니다.

| 단계 | 자동 여부 | 사용 수단 |
|---|---|---|
| 연관 키워드 발굴, 검색량, 경쟁도 | 자동 | 네이버 검색광고 API (공식) |
| 상위 노출 글 역분석 | 자동 | 네이버 오픈API 검색 (공식) |
| 제목 후보, 목차 설계, 태그 | 자동 | 로컬 분석 |
| 본문 초안 | 자동 | Claude API |
| 사진 리사이즈·EXIF 정리·중복 검사 | 자동 | 로컬 (Pillow) |
| 발행 전 품질 검사 | 자동 | 로컬 분석 |
| **경험·수치 채우기** | **사람** | — |
| **발행** | **사람** | 스마트에디터 |

읽기 전용 공식 API와 내 컴퓨터 안에서의 파일 처리만 씁니다. 약관 위반이 없고,
발행 패턴이 사람의 것이므로 어뷰징 신호가 남지 않습니다.

## 마지막 두 개는 왜 사람이어야 하나

기술적 제약 때문이 아니라, **그게 상위 노출의 실제 조건이기 때문**입니다.

네이버의 D.I.A. 계열 로직은 "이 문서에 작성자만 쓸 수 있는 정보가 있는가"를 봅니다.
직접 가본 후기, 실제로 낸 금액, 실패한 경험, 본인이 찍은 사진 — 이건 자동화로
만들 수 없는 종류의 정보이고, 동시에 상위권과 하위권을 갈라놓는 거의 유일한 차이입니다.

초안에 `{{직접 채우기}}` 를 일부러 남겨두는 것도 그래서입니다. 그 자리를 채우는
10분이 이 도구에서 가장 중요한 10분입니다.

## 안전한 운영 수칙

- 하루 1편. 몰아서 올리지 않습니다.
- 발행 시간을 매번 조금씩 다르게 합니다.
- 사진은 직접 찍은 것만. 같은 사진 재사용 금지 (`build` 가 중복을 잡아줍니다).
- 키워드 밀도 2% 이하 (`audit` 가 검사합니다).
- 협찬을 받았으면 본문에 명시합니다. 표시광고법상 의무이고, 미표시는 과징금 대상입니다.
- 같은 주제를 조금씩 바꿔 여러 편 쓰는 것(유사문서 양산)을 피합니다.
